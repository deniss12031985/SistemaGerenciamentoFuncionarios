# Sistema de Gerenciamento de Funcionários e Folha de Pagamento

Atividade avaliativa de Programação Orientada a Objetos em Java.

## Objetivo
Gerenciar funcionários CLT, PJ e comissionados, calcular suas
remunerações e gerar relatórios da folha de pagamento.

## Tecnologias
- Java
- Maven
- JUnit 5
- Git e GitHub

## Status
Em desenvolvimento.
